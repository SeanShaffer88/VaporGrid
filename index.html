Component usage

Give each view one main decision or action. Let its supporting controls share space and keep current state visible with text, shape, or a marker alongside color.

Surface levels

Surface 1 · workspace base
Surface 2 · compartment
Surface 3 · raised surface

Use a higher level to show structure. Keep dense rows flat and use boundaries or labels where a surface difference alone would be hard to distinguish.

Actions and state

Try a primary action in the workspace

Lead with one neutral primary action and a clear verb. Reserve crimson for focus, selection, or a clearly labeled destructive confirmation. Pair color with visible text and programmatic state.

Panels and preferences

When to use a drawer

Open related settings or details in context. Reserve full workspaces for tasks that need their own navigation. Apply reversible appearance settings immediately and keep staged layout changes available until the user chooses Apply or Cancel.

Try the Settings drawer

Keyboard commands

Use the visible Commands control or Ctrl / ⌘ + K in the workspace. Search for available commands, activate one, or press Escape to dismiss the palette.

Keep frequent commands available through their visible controls as well.

Try the command palette

Accessibility target and evidence

VaporGrid targets WCAG 2.2 AA and uses a separate project touch target of 44 × 44 CSS pixels. The verification record distinguishes measured checks from outstanding browser and assistive technology work.
